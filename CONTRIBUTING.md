# Contributing to awesome-etl

The premise of this list is that you don't need fancy, specialized ETL frameworks. Well-structured scripts using mainstream, well-supported libraries get you surprisingly far. The warning at the top of the GUI tools section is intentional and reflects the same thinking. Tools are curated for real adoption and staying power, with a strong preference for open source.

## What belongs

Tools should be genuinely useful in production ETL work, not just tangentially related. Open source is strongly preferred. Proprietary tools are fine where that's expected (cloud services, hosted platforms), but should be noted if they appear elsewhere. If you built the tool, it needs to have real third-party traction to be considered. PRs that read like a product launch will be closed. Removals of abandoned or superseded tools are welcome.

## Descriptions

Quote the tool's own words where possible, pulled from the GitHub description or official docs. If no usable description exists, write a plain factual sentence about what the tool does. One sentence only. No marketing copy, no editorializing, no second sentence adding your own context.

## Formatting

- Entries follow `* [Name](url) - description.`
- Alphabetical order within each section (case-insensitive)
- Put tools in the right existing section. If nothing fits, ask in the PR before creating a new one
- Prefer canonical, stable URLs (official site or GitHub org root)
- Keep links current; update dead links and moved pages

## Submitting

Open a PR with a brief note on what the tool does, why it belongs here and not elsewhere on the list, and some signal of adoption (stars, downloads, known users). PRs without this context will be closed.
